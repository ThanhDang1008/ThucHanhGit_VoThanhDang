## 2. Mục Tiêu Bài Tập
Thành thạo các thao tác quản lý phiên bản với Git và GitHub trên hệ điều hành Kali Linux, từ các lệnh cơ bản đến các quy trình làm việc nâng cao (Branching, Merging, Rebasing, Stash, Submodule, Actions/Pages).

## 3. Các Kỹ Thuật Đã Thực Hiện
- **Cấu hình & Luồng làm việc cơ bản:** Khởi tạo repo, `add`, `commit`, thiết lập `.gitignore`.
- **Thao tác Nhánh (Branching):** Tạo nhánh `feature/*`, rẽ nhánh, gộp nhánh (`merge`), xử lý xung đột (`conflict resolution`).
- **Lịch sử & Hoàn tác:** Xem log (`git log`), hoàn tác local (`git restore`), hoàn tác remote (`git revert`), truy vết lỗi (`git bisect`), khôi phục commit (`git reflog`).
- **Remote & Đóng gói:** Kết nối SSH & HTTPS, tạo Release Tag (`v1.0.0`), gửi Pull Request, thiết lập GitHub Pages.
- **Tính năng nâng cao:** Sử dụng `git stash`, tạo `alias`, tích hợp `submodule`.
